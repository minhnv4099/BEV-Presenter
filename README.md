# The project of COMP-5421: BEV Presenter.

This project re-implements the code about [BEV](https://arxiv.org/abs/2203.17270) paper.
The code is consulted from [the repository](https://github.com/fundamentalvision/BEVFormer).

# Installation
Use **uv** to install dependencies in [uv.lock](uv.lock). (need to make compatible)

## NOTE
Should run any file by ```uv run ...```.

## Download data
Download data from ... to [nuscenes](data/nuscenes) named the folder 'v1.0-mini'.

Inspect [nuscenes_infos_temporal_train_mono3d.coco.json](data/nuscenes/nuscenes_infos_temporal_train_mono3d.coco.json) to inspect data. 
Visit https://www.nuscenes.org/nuscenes for more information.
